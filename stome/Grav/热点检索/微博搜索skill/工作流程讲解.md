🔧 使用方式

快速启动

_# 1. 创建分析表格_

飞书多维表格 → 创建"微博热搜商机分析"表格 → 添加8个字段

_# 2. 采集热搜数据_

浏览器打开：https://s.weibo.com/top/summary

搜索关键词：地面、酒店、出行、旅行、目的地

_# 3. 搜索五星酒店_

Google搜索："地点 + 周边 + 五星级酒店"

_# 4. 填充表格并分析_

按六维框架分析 → 评估商机价值 → 输出业务方案
