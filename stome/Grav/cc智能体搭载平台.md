当前选定飞书和微信两个平台
## 优劣对比
#### 飞书
- 开放的api更多（权限更大），能够做的事情更多，包括给置顶人员定时发消息
- 飞书有更加齐全的办公插件，包括飞书云文档、多维表格、日历日程、任务代办等，可以更好的搭配ai进行使用
- 飞书可以实现多Agent的群聊写作
	- 可以把成员拉入群聊，同时调用，根据不同的群组和任务使用不同的Agent
#### 微信
- 个人用户使用场景更多
- 环境比较封闭，能够调用和使用的功能有限
- 门槛较低，只需要扫码就可以连接
- 仅提供个人使用，无法建立群聊或者分享他人使用，只能接受扫码人员的消息

| **特性 / 限制** | **微信接入 (ClawBot)**             | **飞书接入**                |
| ----------- | ------------------------------ | ----------------------- |
| **流式交互**    | ✗ **不支持**（必须等后台完全生成完，再一整块吐出来）  | ✓ **支持**（逐字输出，复杂任务体验极佳） |
| **消息渲染**    | ⚠️ Markdown 渲染不完整，复杂的表格或代码块会乱序 | ✓ 完美支持标准的 Markdown 排版   |
| **时效限制**    | ⚠️ 存在 24 小时交互时效限制，超时可能需要重新触发   | ✓ 属于长连接或标准 Webhook，随时可用 |
| **部署成本**    | 极低，扫码或简单配置通道即可                 | 较高，需要一定的开发/配置飞书开放平台权限   |
| **协作能力**    | 弱，通常只适合个人接收推送和一问一答             | 极强，支持群聊、@ 调用、云文档联动      |
