
| 步骤       | 做什么                                | 产出                        |
| -------- | ---------------------------------- | ------------------------- |
| 1. 数据采集  | 8平台并行抓热搜（百度/微博/知乎/头条/抖音/36氪/B站/贴吧） | 各平台原始榜单数据                 |
| 2. 交叉验证  | 跨平台合并同一条热点，去重                      | 合并后的热点集合                  |
| 3. 商机分析  | 逐条打标签：关联地点/景点/商机建议/优先级             | 商机清单（⭐高/中/低）              |
| 4. 建主表   | 创建 Bitable + 字段 + 批量插入 + 公开权限      | 热点商机多维分析表（每条含备注链接）        |
| 5. 深度子表  | 为高/中优先级地区建子表：酒店/景点/美食/活动           | 5个地区子表（塞尔维亚/上海/云南/张家界/乐山） |
| 6. 文旅调研  | 8维度拆解每个地区文化文旅符号                    | 地区文旅符号调研表（5个地区）           |
| 7. 建内容库表 | 创建子表，配字段：酒店名称(Select)+内容品类(Select) | 笔记裂变内容库表                  |
| 8. 生成笔记  | 对每家酒店写8个品类的笔记正文                    | 8品类×N酒店 = N×8篇完整笔记        |
| 9. 验证修复  | 检查酒店名称非空、符号替换、去金额                  | 清洁数据                      |
