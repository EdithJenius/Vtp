# 🚀 小红书笔记 → 飞书多维表格 采集器

> 一键推送小红书笔记到飞书多维表格，支持图文内容、高清图片、视频URL、视频文案提取

## 架构

```
用户复制链接 → 发给飞书机器人
         ↓
  [Feishu Bot] 接收消息
         ↓
  [Xiaohongshu Extractor] 抓取笔记
    ├─ 笔记标题+正文
    ├─ 高清图片(多张)
    ├─ 视频URL
    └─ 视频文案/字幕
         ↓
  [Feishu Bitable API] 写入表格
         ↓
  ✔ 多维表格自动更新
```

## 技术方案

| 组件 | 方案 | 说明 |
|------|------|------|
| 飞书机器人 | Feishu Open API (自建应用) | 接收消息、写入多维表格 |
| 内容抓取 | Puppeteer/Playwright | 渲染小红书SPA页面，提取数据 |
| 多维表格 | Feishu Bitable API | 创建/更新记录，支持图片附件 |
| 部署 | 服务器/云函数 | 保持恒定运行 |

## 快速开始

### 1. 飞书自建应用配置

1. 打开 [飞书开放平台](https://open.feishu.cn/app)
2. 创建企业自建应用 → 取名"小红书笔记采集器"
3. 开启以下权限：
   - `im:message` - 接收和发送消息
   - `bitable:app` - 操作多维表格
   - `drive:drive` - 上传图片附件
4. 发布应用

### 2. 配置多维表格

创建一张飞书多维表格，添加以下字段：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 笔记ID | 文本 | 小红书笔记唯一ID |
| 标题 | 文本 | 笔记标题 |
| 正文 | 文本 | 笔记文本内容 |
| 图片 | 附件(多图) | 高清图片预览 |
| 视频 | 文本/URL | 视频链接 |
| 视频文案 | 文本 | 自动转写的文字稿 |
| 链接 | 链接/URL | 原文链接 |
| 发布时间 | 日期 | 笔记发布时间 |
| 作者 | 文本 | 发布者昵称 |
| 收藏时间 | 日期 | 你收藏此笔记的时间 |

### 3. 安装并运行

```bash
# 克隆项目
git clone <this-repo>
cd feishu-xiaohongshu-collector

# 安装依赖
npm install puppeteer @larksuiteoapi/node-sdk

# 复制并配置环境变量
cp .env.example .env
# 编辑 .env 填入飞书应用凭证

# 启动服务
node src/bot.js
```
