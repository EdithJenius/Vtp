## 一、需求审查结论

### 一句话定位

为农村自建房和独栋别墅甲方，按面积段预制多套主流方案供快速选择，不满意再单独定制。

### 核心需求（优先级排序）

| 优先级 | 内容 | 说明 |
|--------|------|------|
| **P0** | 平面方案库 | 各面积段×风格的标准平面布局，出CAD+PDF |
| **P1** | 效果图 | 各方案配套外观/室内效果图 |
| **P1** | 施工图 | 各方案配套施工图（结构/水电等） |
| **P2** | 项目流程SOP | 接单→设计→施工→交付标准化流程 |
| **P2** | 知识沉淀系统 | 项目复盘归档、经验库沉淀 |

### 第一期范围（P0 — 平面方案）

仅做平面图层面，覆盖全面积段和风格，为甲方提供「菜单式」选型。

### 明确不做的（当前）

- 效果图制作
- 施工图深化
- 现场施工管理
- 建材供应链整合

### 方案编号规则

```
H-{面积}-{风格代码}-{序号}
```

| 字段 | 说明 | 示例 |
|------|------|------|
| H | House 前缀 | H |
| {面积} | 面积数字 | 120 / 150 / 160 / 180 / 200 |
| {风格代码} | C=新中式(Chinese), M=现代(Modern) | C / M |
| {序号} | 该组合下第几套方案 | 01 / 02 / 03 |

**示例：** `H-150-C-02` → 150㎡新中式方案二

## 四、单套方案内容规范

每套方案文件夹内包含以下内容：

### 必需（平面方案阶段）

| 文件 | 格式 | 说明 |
|------|------|------|
| 方案说明 | `.md` | 方案定位、户型特点、适用场景 |
| 平面图CAD | `.dwg` | 标准CAD源文件 |
| 平面图PDF | `.pdf` | 出图打印用 |

### 方案说明文档模板

```markdown
## H-150-C-02 — 150㎡新中式方案二

### 基本信息
- **面积：** 150㎡
- **风格：** 新中式
- **层数：** 2层（方案A）/ 3层（方案B）
- **户型：** 4室2厅3卫

### 户型特点
- 一层：南北通透客餐厅一体，老人房朝南带独立卫生间
- 二层：主卧套房（衣帽间+主卫），两间次卧，起居室
- 三层（如有）：露台+多功能房

### 适用场景
- 宅基地进深12-15m，面宽10-12m
- 适合三代同堂，老人房设在一层

### 设计要点
- 客厅挑空设计，增强空间感
- 新中式元素：坡屋顶、木质格栅、庭院
- 动静分区明确

### 甲方沟通要点
- 可调整：楼梯位置、露台面积、卫生间布局
- 不可调整：承重墙位置、主体结构
```

## 五、平面方案设计原则

### 通用原则
- 每户至少保证：**3室2厅**（120㎡起步）
- 老人房必须设在一层
- 主卧标配：**套房设计**（独立卫生间+衣帽间，150㎡以上）
- 厨房与餐厅相邻，动线最短
- 客厅朝南，采光优先

### 新中式风格要点
- 对称布局、中轴线
- 坡屋顶/小青瓦
- 木质格栅、花窗元素
- 庭院/天井预留
- 堂屋/神龛位（农村刚需）

### 现代简约风格要点
- 非对称布局、体块穿插
- 平顶/单坡顶
- 大面积玻璃、落地窗
- 简洁外墙（真石漆/石材）
- 露台/阳台一体化
