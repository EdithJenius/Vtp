### 5. 技术踩坑
- faster-whisper medium 模型在 CPU 上处理2分钟视频约需2-3分钟，偶尔OOM
- 大量视频建议用 small 模型（更快，质量可接受）
- opencli browser 的 eval 用 var 而非 let 避免跨调用变量冲突
- douyin API 直链有时效性，获取后需立即下载
- 大部分 douyin 视频 is_subtitled=0（无内置字幕）
- json.loads(f.read().decode()) 的 Unicode … 字符污染问题
- `"Bearer " + TOKEN` vs `***` 的字符转义问题
