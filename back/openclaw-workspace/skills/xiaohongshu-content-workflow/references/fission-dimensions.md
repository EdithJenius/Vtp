# 小红书内容裂变驱动维度参考

## 1. 时间/事件驱动
| 时间节点 | 选题方向 | 适合业务 |
|---------|---------|---------|
| 520/情人节 | 蜜月旅行、情侣酒店 | 酒店+机票 |
| 暑假(6-8月) | 亲子游、毕业旅行、避暑 | 机票+酒店 |
| 国庆/五一 | 长线游、出境游 | 机票+签证+酒店 |
| 演唱会/赛事 | 观赛团、粉丝出行 | 票务+酒店 |
| 航司大促日 | 特价机票攻略 | 机票 |
| 节假日倒计时 | "再不订就涨价了" | 全业务 |

## 2. 圈层/兴趣驱动
| 人群 | 痛点 | 内容策略 |
|------|------|---------|
| 毕业生 | 预算有限、想纪念 | 穷游攻略、毕业旅行清单 |
| 亲子家庭 | 带娃累、安全第一 | 亲子酒店测评、遛娃攻略 |
| 情侣/蜜月 | 要浪漫、要出片 | 情侣酒店、蜜月圣地 |
| 商务人士 | 高效、有面子 | 商务舱攻略、高端酒店 |
| 追星族 | 抢票、周边酒店 | 演唱会攻略+住宿打包 |
| 打工人 | 假少、想放松 | 周末游、短途度假 |

## 3. 精神/审美驱动
- 自然美学：雪山、极光、草原、星空
- 人文美学：古镇、建筑、在地文化
- 影视美学：跟着电影/综艺去旅行
- 设计美学：设计酒店、艺术展
- 打卡美学：原相机直出、天然滤镜

## 4. 感官/生活驱动
- 味蕾旅行：为了吃飞一座城
- 夏日感官：海风、冰饮、泳池
- 市井烟火：菜市场、老街、夜市
- 季节限定：当季风景

## 5. 疗愈/松弛驱动
- 逃离城市：周末短途、放空
- 寺庙/禅修：祈福、静心
- 森林/温泉：自然疗愈
- 躺平旅行：酒店躺、不出门

## 6. 物欲/仪式感驱动
- "人生必住"：奢华酒店清单
- "攒钱打卡"：存钱目标
- "一生一次"：蜜月、求婚
- "升舱自由"：消费升级
