# 热点→地点转化规则

> 目的:将全网热搜中的宽泛话题,转化为具体的旅游目的地/避险地/商机区域。
> 原则:拒绝「全国」,每个热点绑定可落地的具体地点。

---

## 一、热点分类与转化逻辑

### A 类：自然灾害 / 安全事件 → 反向分析（避险地）

**逻辑:** 灾害发生地不宜旅游 → 推荐远离灾害的安全替代目的地。

| 热点类型 | 示例 | 分析方向 | 推荐地点 |
|---------|:----|:--------|:---------|
| 地震/海啸 | 菲律宾7.9级地震 | 沿海城市有海啸风险,推荐内陆/高地 | 丽江/大理/昆明/成都/贵阳 |
| 高温/热射病 | 男子夜班体温41度去世 | 南方高温城市不宜,推荐避暑胜地 | 六盘水/贵阳/昆明/大理/长白山/川西 |
| 台风/洪水 | — | 避免沿海,推荐内陆山区 | 贵州/云南/四川西部 |
| 疫情/公共卫生 | — | 避免高风险区,推荐安全区 | 低风险目的地 |

### B 类：教育 / 考试 / 毕业 → 正向分析（消费热点地）

**逻辑:** 时间窗口(高考结束) + 热门需求(毕业旅行) → 年轻人欢迎的目的地。

| 热点类型 | 示例 | 分析方向 | 推荐地点 |
|---------|:----|:--------|:---------|
| 高考/毕业 | 2026高考 | 考后减压、毕业旅行爆发地 | 三亚/成都/重庆/长沙/西安/大理 |
| 学霸话题 | 女孩估分149-150 | 研学营、学霸同款线路 | 北京(清北)/曲阜(国学)/西安(历史) |
| 暑期/亲子 | — | 亲子友好、主题乐园 | 北京环球/上海迪士尼/广州长隆 |

### C 类：社会文化 / 娱乐 → 正向分析（情绪热点地）

**逻辑:** 话题引发的情绪/兴趣 → 对应的体验型目的地。

| 热点类型 | 示例 | 分析方向 | 推荐地点 |
|---------|:----|:--------|:---------|
| 外星人/星空 | 发现外星生命须通报联合国 | 好奇心驱动,推荐星空观测/天文主题 | 宁夏沙坡头/青海茶卡/西藏阿里/云南丽江 |
| 夜市/地摊 | 地摊设备暴涨600% | 烟火气消费,推荐夜市经济城市 | 长沙/重庆/成都/西安/广州/南宁 |
| 综艺/影视 | 浪姐/歌手 | 取景地+明星同款 | 取景城市/拍摄地 |
| 体育赛事 | NBA总决赛 | 体育旅游+户外运动 | 观赛团(国外) + 国内户外(新疆/云南) |
| 音乐节 | — | 年轻人聚集地 | 上海/成都/杭州/草莓音乐节城市 |

### D 类：经济 / 消费 → 正向分析（商机地）

**逻辑:** 消费趋势变化 → 受影响最显著的旅游市场。

| 热点类型 | 示例 | 分析方向 | 推荐地点 |
|---------|:----|:--------|:---------|
| 消费降级 | 燃油车价格雪崩 | 穷游/性价比游需求上升 | 淄博/柳州/乐山/长沙(低消费美食) |
| AI+旅游 | AI抢酒店流量 | AI应用最活跃城市 | 杭州/深圳/北京/上海 |
| 股市/汇率 | 韩国股市 | 汇率优势→出境游成本变化 | 关注韩元/日元汇率→济州岛/首尔/东京 |

### E 类：国际事件 / 综合 → 正向+反向结合

| 热点类型 | 示例 | 分析方向 | 推荐地点 |
|---------|:----|:--------|:---------|
| 世界杯/大型赛事 | 美加墨世界杯 | 正向→观赛主办城市 | 墨西哥城/洛杉矶/纽约/多伦多 |
| 国际外交/免签 | 特朗普访华要免签 | 正向→签证利好目的地 | 泰国/新加坡/马来西亚（免签国） |
| 科技突破 | 清洁低碳氢煤混烧 | 正向→科技旅游/研学 | 合肥(科学岛)/深圳(新能源)/酒泉(航天) |

## 二、转化流程（5步法）

```
热点话题 → 分类(A/B/C/D/E) → 判断正反向 → 提取关键词 → 匹配具体地点
```

### Step 1: 识别热点类别
- 有灾害关键词(地震/台风/高温/疫情) → A 类,反向分析
- 有时间+人群关键词(高考/毕业/暑期) → B 类,正向分析
- 有情绪+文化关键词(夜市/星空/综艺) → C 类,正向分析
- 有经济关键词(股市/消费/AI) → D 类,正向分析
- 有国际+综合关键词 → E 类,双向分析

### Step 2: 判断正反向
- **正向:** 热点在哪里 → 目的地就在哪里(或话题相关的目的地)
- **反向:** 热点在哪里不好 → 推荐安全替代目的地

### Step 3: 提取关键词
从话题中提取地名/品类/情绪:
```
"男子夜班关闭门窗体温飙41度去世" → 关键词: 高温/避暑/安全
"2026高考" → 关键词: 毕业/减压/旅行
```

### Step 4: 匹配具体城市/景区
用关键词从旅游知识库中匹配:
```
避暑 → 六盘水/贵阳/昆明/大理/长白山/川西
毕业 → 三亚/成都/重庆/长沙/西安/大理
星空 → 宁夏沙坡头/青海茶卡/西藏阿里
```

### Step 5: 校验
- ❌ 拒绝「全国」「各地」「所有」等宽泛表述
- ✅ 必须写 1-3 个具体城市名或景区名
- ✅ 自然危害必须有避险推荐

## 三、热点→地点转化示例

### 示例1: 自然灾害类
```
话题: 菲律宾群岛7.9级地震
分类: A(地震/海啸)
分析方向: 反向(避险)
关键词: 地震/海啸/沿海
转化结果:
  关联地点: 菲律宾群岛(隐患),推荐避险:昆明/大理/丽江(内陆、无海啸风险)
  关联旅游景点: 昆明滇池、大理古城、丽江古城
  商机分析: 菲律宾海岛游退订潮,替代方案转向国内云南避暑游
```

### 示例2: 社会热点类
```
话题: 发现外星生命须立即通报联合国
分类: C(好奇心/探索)
分析方向: 正向(体验)
关键词: 外星/星空/天文
转化结果:
  关联地点: 宁夏中卫·沙坡头、青海茶卡盐湖、西藏阿里
  关联旅游景点: 沙坡头星空营地、茶卡盐湖星空、阿里天文台
  商机分析: 借外星话题推「暗夜星空旅游」,暑期亲子观星研学
```

### 示例3: 经济类
```
话题: 地摊设备暴涨600%,夜市摆摊大军回来
分类: D(消费降级/烟火气)
分析方向: 正向(消费)
关键词: 地摊/夜市/烟火气
转化结果:
  关联地点: 长沙、重庆、成都、西安
  关联旅游景点: 长沙太平街夜市、重庆解放碑夜市、成都玉林路
  商机分析: 夜市经济爆发→推「夜市美食游」「烟火气城市探索」产品线
```

### 示例4: 教育类
```
话题: 2026高考
分类: B(毕业/暑期)
分析方向: 正向(消费)
关键词: 高考/毕业/暑期/减压
转化结果:
  关联地点: 三亚、成都、重庆、长沙、西安、大理
  关联旅游景点: 三亚蜈支洲岛、成都大熊猫基地、长沙橘子洲、西安大唐不夜城
  商机分析: 毕业旅行截流窗口,快速上架减压游/毕业团/准考证优惠
```

## 四、常见错误与修正

| ❌ 错误写法 | ✅ 正确写法 |
|:-----------|:-----------|
| 全国 | 三亚/成都/重庆/西安(至少列3个) |
| 避暑目的地 | 六盘水/贵阳/昆明/大理(具体城市) |
| 各地夜市 | 长沙/重庆/成都/西安(具体夜市) |
| 主题乐园 | 上海迪士尼/北京环球影城/广州长隆 |
| 海边 | 三亚/厦门/青岛/北海(具体海滩) |
| - (空) | 必须有内容,至少1个具体地点 |
