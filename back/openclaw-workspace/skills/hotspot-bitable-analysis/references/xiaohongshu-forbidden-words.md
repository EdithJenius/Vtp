## 二、🤖 自动合规校验脚本模块

此脚本可直接 `import` 到笔记生成流程中，产出笔记正文后自动扫描并替换违禁词。

```python
#!/usr/bin/env python3
"""
xiaohongshu_compliance.py - 小红书内容合规自动校验模块
用法: from xiaohongshu_compliance import audit_and_fix
      clean_text = audit_and_fix(raw_text)
"""

# 违禁词 → 合规替换 映射表（长匹配优先）
REPLACEMENT_TABLE = [

def audit_and_fix(text):
    """
    扫描文本中的违禁词并替换为合规表达。
    返回：(clean_text, violations_list)
    - clean_text: 替换后的合规文本
    - violations_list: 被替换的违禁词列表
    """
    if not isinstance(text, str) or not text.strip():
        return text, []
    
    violations = []
    # 长词优先匹配，避免短词先匹配干扰
    sorted_rules = sorted(REPLACEMENT_TABLE, key=lambda x: -len(x[0]))
    
    for forbidden, replacement in sorted_rules:
        if forbidden in text:
            if replacement:
                text = text.replace(forbidden, replacement)
                violations.append(f"{forbidden} → {replacement}")
            else:
                # replacement 为空字符串表示直接删除这个词
                text = text.replace(forbidden, "")
                violations.append(f"{forbidden} → [删除]")
    
    return text, violations


def audit_report(text):
    """
    返回详细的审计报告，包括原文对比和违规统计
    """
    if not isinstance(text, str) or not text.strip():
        return {"original": text, "clean": text, "violations": [], "count": 0}
    
    clean, violations = audit_and_fix(text)
    return {
        "original": text,
        "clean": clean,
        "violations": violations,
        "count": len(violations)
    }


if __name__ == "__main__":

    result = audit_report(test_text)
    print(f"原文: {result['original']}")
    print(f"合规: {result['clean']}")
    print(f"违规项 ({result['count']}):")
    for v in result['violations']:
        print(f"  - {v}")
```

## 三、📋 笔记生成流程中的合规嵌入

在笔记裂变生成流程中，产出一篇笔记正文后立即执行：

```
产出一篇正文文案
  ↓
执行 compliance.audit_and_fix(body)
  ↓
若有违规 → 自动替换 → 记录日志
若无违规 → 保持原样
  ↓
写入 Bitable
```

### 集成方式

在 `/tmp/generate_all_notes.py` 或类似脚本顶部：

```python
from xiaohongshu_compliance import audit_and_fix

# 在每条笔记的正文生成后：
for record in all_records:
    body = record["正文文案"]
    clean_body, violations = audit_and_fix(body)
    if violations:
        print(f'[合规] {record["笔记标题"][:20]} - {len(violations)}处替换')
    record["正文文案"] = clean_body
```

## 四、⚠️ 合规校验优先级速查

```
🔴 红线级（触碰必封号）:
  涉政言论、涉黄内容、涉暴内容
  烟酒药品、违禁品、假冒伪劣
  诈骗/刷单/刷粉
  → 生成本身就不应出现，出现即废稿

🟠 严查级（限流/删帖）:
  绝对化用语、医疗健康夸大的
  公开引流（微信/外链/二维码）
  虚假效果承诺
  → 自动替换，输出替换日志

🟡 关注级（可能影响权重）:
  标题党、夸张标题
  评论区私信过度引流
  话题标签踩红线
  → 在备注字段提醒注意

🟢 建议级（优化推荐）:
  原创度检查
  图片文字OCR风险
  多账号内容查重
  → 备注标注
```
