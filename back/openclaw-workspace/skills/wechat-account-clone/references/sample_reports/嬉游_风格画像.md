# 嬉游 · 风格画像报告

**公众号**: 嬉游
**作者/IP**: 急速菜菜
**文章**: 茶园中醒来，松林里入睡。这家火了十多年的酒店，等来了好价

## 基础定位

- **定位**: 旅行商品带货KOL — 推荐靠谱的旅行商品，从不售卖任何旅行产品
- **受众**: 想薅羊毛的旅行消费者、中产度假人群
- **核心主张**: "让你更聪明地去旅行" — 帮读者省钱+省心

## 标题公式

- **结构**: 场景描写 + 数字/价格钩子
- **长度**: 20-30字
- **Emoji**: 少用或不用
- **典型模式**: 「场景金句 + 利益钩子」
- **例句**: *"茶园中醒来，松林里入睡。这家火了十多年的酒店，等来了好价"*

## 开头策略

- **类型**: 共识建立型 → 转折 → 利益直给
- **模式**:
  1. 第一句先建立共识（"去杭州绕不开两个地方"）
  2. 转折（"但如果你想安静..."）→ 引出推荐
  3. **直接先Po商品**（价格、套餐内容、有效期）
- **特点**: 不铺垫，不让读者等，先甩硬货再看细节

## 正文结构

- **节奏**: 中速，段落3-5句
- **组织**: 总-分结构
  - 先给结论（商品信息+价格+购买方式）
  - 再分拆（背景→设计→房间→餐饮→周边）
- **分层**: 使用小标题式过渡（"先Po商品"、"说说位置"、"说完硬件说餐饮"）
- **信息密度**: 极高 — 品牌名/设计师/面积/备品/价格 密集输出

## 语气调性

- **人称**: 第一人称（"我"）为主，偶尔第二人称（"你"）
- **正式度**: 口语化，像朋友聊天
- **情绪浓度**: 中高 — "聪明如我对不对"、"用过的都会上头"
- **标志性语气**: "对不对"、"哦"、"呢" 常用，带点小得意

## 转化手法（核心卖点）

1. **先Po商品** → 文章第三段直接甩价格套餐
2. **价格锚点** → "和日历比，差价真的很大哦"
3. **购买教程** → 教你怎么用券凑单"聪明如我对不对"
4. **无风险** → "不约可退、过期自动退、不核销可随时退"
5. **多链接** → 主套餐+早餐券+飞猪券，三个链接穿插
