# Route Analysis: 垂直行业深度分析

> **定位：看新闻 → 对库存 → 抓刚需**
> 面向国际航班、奢华酒店等高客单/重决策业务，信息源从热搜转向上游产业链和垂直行业数据。

## 与 hotspot-bitable-analysis 的核心差异

| 维度 | hotspot-bitable-analysis | route-analysis |
|------|------------------------|----------------|
| **锚点** | 泼天流量 + 年轻人情绪 | 看新闻 + 对库存 + 抓刚需 |
| **业务场景** | 大众旅游/经济型住宿 | 国际机票/奢华酒店/高客单价 |
| **决策周期** | 即时种草，短决策链 | 重决策，长决策链 |
| **信息源** | 微博/抖音/小红书热搜 | 行业新闻/运力数据/政策/供应链 |
| **受众** | C端泛流量 | B端从业者/高净值客群 |
| **产出** | 小红书笔记 | 行业简报/库存建议/决策依据 |

## 🧠 分析框架：三层漏斗

```
Layer 1: 信号捕获（看新闻）
  ├── 新开航线/加密航班 → 供给增加
  ├── 签证政策变化 → 阀门开关
  ├── 酒店品牌入驻 → 目的地升温
  ├── 大型会展排期 → 集中需求
  └── 地缘/安全事件 → 需求转移

Layer 2: 库存核对（对库存）
  ├── 航空公司运力 vs 历史同期对比
  ├── 奢华酒店可用房态 vs 预订率
  ├── 竞品价格带监测
  └── 供应链瓶颈（宽体机交付/酒店建造）

Layer 3: 刚需捕捉（抓刚需）
  ├── 确定性需求：会展/留学/商务
  ├── 弹性需求：旅游/探亲/购物
  ├── 替代需求：地缘事件导致的需求转移
  └── 窗口期：淡旺季过渡的价差套利
```
