# 素材需求模板 — 运营剪辑素材采购标准 v1.0

> 来源：运营剪辑实际需求
> 日期：2026-06-03
> 用途：video-generation skill 中「素材匹配 → 素材搜索与下载」环节的输出标准

---

## 一、酒店素材精准需求

### 基础信息
- 酒店名称（中英文）
- 所在城市/区域

### 素材用途与平台
- 用于：小红书视频 / 抖音
- 视频风格：高级感 / 探店评测 / 种草向 / 攻略向
- 视频时长：10分钟以内

### 视觉风格
- 主色调：暖 / 冷 / 黑白 / 莫兰迪 / 复古
- 光线：自然光 / 暖黄灯 / 金色时刻 / 夜景
- 构图：全景 / 特写 / 俯拍 / 第一人称

### 需要的场景（多选）
- 外观/建筑
- 客房（床/浴室/窗景/阳台）
- 餐厅/酒吧
- 泳池/水疗
- 花园/露台/沙滩
- 特色细节（旋转楼梯/艺术品/备品/灯具）
- 周边环境/地标景观

### 特殊限制
- ❌ 不要出现 LOGO/水印
- ❌ 不要出现字幕
- ❌ 不要阴天/雨天素材（或要特定季节）
- ❌ 不要有太多客人（要空镜）
- ✅ 画面稳定性高，不能左右移动太快
- ✅ 1080p以上，30fps以上
- ✅ 横屏16:9 / 竖屏9:16
- **需要数量：30条**

## 二、动物素材精准需求

### 基础信息
- 目的地：坦桑尼亚 / 肯尼亚 / 两者都有
- 国家公园/保护区：塞伦盖蒂、马赛马拉、恩戈罗恩戈罗、安博塞利等
- 主要动物种类：角马/斑马/狮子/猎豹/大象/长颈鹿/火烈鸟/河马/犀牛等
- 特殊场景：天河之渡/捕猎/迁徙/打斗/母子互动

### 素材用途与风格
- 用于：小红书视频 / 抖音
- 视频风格：壮观 / 治愈 / 科普 / 野奢 / 探险 / 唯美
- 画面情绪：紧张 / 震撼 / 温馨 / 宁静 / 活力

### 视觉技术要求
- 画质：4K / 2K / 1080p
- 画面比例：横屏16:9 / 竖屏9:16（统一一个比例）
- 光线：金色时刻（日出日落）/ 白天强光 / 阴天柔和
- 镜头类型：远景（大迁徙场面）/ 中景（动物群体）/ 特写（眼睛/毛发/动作细节）/ 航拍
- **需要数量：50条**

### 环境与季节
- 季节：旱季（7-10月）/ 雨季（11-5月）/ 不限
- 背景元素：草原/河流/火山口/雪山（乞力马扎罗）/ 合欢树/ 尘土飞扬

### 版权与来源偏好
- 无字幕
- 需要提供下载链接

- 画质：4K / 2K / 1080p
- 画面比例：横屏16:9 / 竖屏9:16（统一一个比例）

### 环境与季节

- 可以有航拍素材

## 四、旅行转场素材精准需求

### 转场核心动作
- 物品/身体部位：机票 / 登机牌 / 护照 / 手 / 背包 / 帽子 / 咖啡杯 / 树叶 ……
- 动作方式：翻转 / 抛起接住 / 快速扫过镜头 / 甩动 / 旋转 / 推近拉远 / 穿墙 / 同方向摇镜 ……
- 是否必须完全遮挡镜头：是 / 否
- 完成时长：不超过30秒

### 视觉风格与技术
- 画面比例：竖屏9:16 / 横屏16:9（统一一个比例）
- 分辨率：4K / 2K / 1080p
- 帧率：30fps
- 光线：自然光 / 暖光 / 冷光 / 明亮
- 无Logo/无水印/无字幕
- **需要数量：10条**

## 五、人物旅行素材精准需求

### 人物基本信息
- 人物类型：单人/情侣/朋友/家庭/背影/侧脸/不露脸
- 年龄/气质：20+ / 30+ / 活泼 / 松弛
- 着装风格：长裙 / 冲锋衣 / 纯色 / 民族风 / 户外休闲
- 是否需要露脸：不露脸 / 可露脸但不强调

### 场景与环境
- 目的地类型：森林/高山/草原/海边/沙漠/湖泊/峡谷
- 具体地理元素：松林、悬崖、海浪、星空、日出
- 天气/光线：阳光斑驳、金色时刻、阴天柔和、蓝调时刻
- 季节：春夏绿意/秋日金黄/冬雪/旱季枯黄

### 动作与情绪
- 动作类型：奔跑/跳跃/散步/静坐/挥手/仰望
- 情绪关键词：自由 / 松弛 / 快乐 / 充满生命力
- 镜头角度：跟拍/固定机位/俯拍/低角度/第一人称
- 是否要有风：吹动头发/裙摆/衣角

### 技术要求
- 分辨率：4K / 1080p
- 画面比例：横屏16:9 / 竖屏9:16（统一一个比例）
- 帧率：25fps / 30fps / 60fps（用于慢动作）
- 时长：每个片段10秒以上
- **需要数量：10条**
