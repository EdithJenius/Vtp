# 新人上岗 · 第一步操作指南

> 新人打开工具后，第一件事：**选客户人群**

---

## Step 0：客户来了，先做三件事

```
□ 1. 客户加微信/进群了
□ 2. 打开 CRM 工具
□ 3. 选择客户人群（下方6选1）
```

---

## 选择人群

### 如何判断客户属于哪类人群？

**听客户说第一句话：**

| 客户说 | → 人群判断 | 优先级 |
|--------|-----------|-------|
| "蜜月/新婚/纪念日" | 👑 奢华蜜月 | ⭐⭐⭐ |
| "一家人/带孩子/全家" | 💼 精英中产家庭 | ⭐⭐⭐ |
| "出差/商务/公司" | ✈️ 精英商务 | ⭐⭐⭐ |
| "展会/广交会/进博会" | 🏪 参展 | ⭐⭐⭐ |
| "第一次/不太懂/小白" | 🌱 年轻人 | ⭐⭐⭐ |
| "到处跑/远程办公/自由职业" | 💻 数字游民 | ⭐⭐ |
| 说不清/问"有什么推荐" | 先问3个问题判断 | — |

**判断不清时的3个必问题：**
1. "您这次出行主要是？"（商务/旅游/探亲/其他）
2. "您平时出行的频率大概？"（高频/中频/低频/第一次）
3. "您有预算范围吗？"（有→按预算推荐；没有→先介绍产品）

---

## 选对人后干什么

**选定人群后 → 系统自动显示该人群的：**
1. ✅ 开场话术
2. ✅ 推荐产品（航司卡/商务舱/酒店）
3. ✅ 必问项清单
4. ✅ 常见异议话术
5. ✅ 红线提示

新人只需要按着走就行。

## 新人每日自查清单

```
□ 今天接手了几个客户？
□ 每个客户打了什么人群标签？
□ 有没有遇到决策树上没覆盖的问题？
□ 如果有 → 点击"未覆盖问题"按钮上报
```

---

## 常见踩坑（新人必读）

❌ **踩坑：** 客户说"蜜月"但预算不高 → 硬推高端产品
✅ **正确：** 按人群走话术，但灵活调整推荐档次

❌ **踩坑：** 客户说"先看看" → 就一直等客户回来
✅ **正确：** 加好友→隔天跟进→名额紧张话术

❌ **踩坑：** 客户问什么就答什么，没有判断人群
✅ **正确：** 前三句话就要判断人群，后面的所有话术按人群走

❌ **踩坑：** 遇到决策树没有覆盖的问题 → 自己瞎回
✅ **正确：** 点"未覆盖问题"上报 + 转专员
