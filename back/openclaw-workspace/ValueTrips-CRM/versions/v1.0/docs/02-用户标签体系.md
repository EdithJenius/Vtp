# 用户人物标签体系设计

> 参考来源：姜Dora访谈15大提问套路 × ValueTrips 客服决策树
> 设计目标：客服3句话内识别用户类型 → 匹配最优话术 → 提升转化

---

## 一、三层标签模型

```
┌─────────────────────────────┐
│   ① 身份标签（基础层）        │  ← 客服开场1-2句可识别
├─────────────────────────────┤
│   ② 需求动机层（认知层）      │  ← 3-5句对话可识别
├─────────────────────────────┤
│   ③ 决策行为层（行动层）      │  ← 贯穿全程的动态标签
└─────────────────────────────┘
```

---

## 二、标签定义

### ① 身份标签（基础层）

| 标签维度 | 可选值 | 识别线索 | 影响的话术策略 |
|---------|-------|---------|--------------|
| 人生阶段 | 学生/刚入职 / 职场3-10年 / 商务人士 / 创业/自由职业 / 退休/高净值 | 对话中提到的场景 | 学生→强调性价比；商务→强调效率 |
| 出行频率 | 高频(月3+) / 中频(月1-2) / 低频(年3次以下) | 提到"经常飞"还是"第一次" | 高频→专业感；低频→多解释 |
| 预算层级 | 低预算 / 中等 / 高净值(≥5万) | 报价反应+主动提预算 | 低→省到即赚到；高→礼遇专属感 |
| 渠道来源 | 小红书 / 朋友推荐 / 老客再购 / 其他 | 对话开头信息 | 推荐→跳过信任；新客→先建信任 |
| 产品兴趣 | 航司卡 / 商务舱 / 酒店 / 综合 | 咨询内容 | 按产品线匹配对应话术 |

### ② 需求动机层（认知层）

| 标签 | 典型信号（客户说的话） | 核心心理 |
|------|---------------------|---------|
| 价格驱动 | "多少钱？" "有优惠吗？" "比XX贵" | 想花最少钱办最多事 |
| 信任焦虑 | "靠谱吗？" "怎么保证？" "跑路了怎么办？" | 怕被骗，需要安全感 |
| 体验追求 | "有什么礼遇？" "能升舱吗？" "高端服务" | 想要尊贵感和差异化 |
| 效率至上 | "最快多久？" "流程复杂吗？" "能不能简化" | 没耐心，要快 |
| 信息收集 | "还有别的选择吗？" "对比一下" | 在比价阶段，还没到决策 |
| 社交验证 | "很多人办吗？" "有成功案例吗？" | 需要从众心理支持 |
| 服务焦虑 | "后续有人管吗？" "出问题找谁？" | 担心售后服务跟不上 |
| 碍于人情 | "朋友介绍的不好意思不问问" | 被动咨询，转化率低 |

### ③ 决策行为层（行动层）— 贯穿全程动态更新

| 标签 | 表现 | 应对策略 |
|------|------|---------|
| 果断行动型 | 问几个问题就要付款 | 减少阻碍，快速推进 |
| 犹豫观望型 | 问完说"我再想想" | 名额紧张话术 + 定期跟进 |
| 理性分析型 | 问细节、问原理、要数据 | 给逻辑框架，尊重理性 |
| 情绪驱动型 | 被故事/案例打动才做决定 | 多抛具体客户案例 |
| 反复比价型 | 多家对比，压价 | 强调差异化和风险对冲 |
| 白嫖咨询型 | 问很多但不打算买 | 适度回复，判断后转跟进池 |

## 三、客服识别标签的对话策略

### 开场30秒内（Step A）

```
客户：你们这个XX卡怎么办？
客服视角（快速打标签）：
  ① 身份线索 → 对话语气、用词（专业vs小白）
  ② 需求线索 → 上来问价格→价格敏感；问流程→效率至上
  ③ 渠道线索 → "朋友说"→推荐；小红书来的→需建信任
```

### 3-5句内确认（Step C）

```
必问项中穿插标签问题：
  - "您之前用过类似服务吗？" → 有经验 vs 小白
  - "您主要想解决什么问题？" → 省钱 / 省时 / 体验升级
  - "您一般飞哪个航司比较多？" → 高频旅客画像
```

### 异议处理时验证（Step D）

```
客户说"太贵了"：
  如果标签是【价格驱动】→ 强调省钱效果
  如果标签是【信任焦虑】→ 先解决信任再谈价格
  如果标签是【体验追求】→ 强调礼遇值这个价
```

## 四、标签组合→行动策略速查

| 常见组合 | 优先策略 | 禁忌 |
|---------|---------|------|
| 学生 + 价格驱动 + 犹豫观望 | 案例打动 + 名额紧张 | 不要滔滔不绝讲产品细节 |
| 商务人士 + 效率至上 + 果断行动 | 快速报价 + 简化流程 | 不要过度寒暄 |
| 高净值 + 体验追求 + 理性分析 | 礼遇清单 + 一对一服务 | 不要只谈价格不谈价值 |
| 朋友推荐 + 信任高 + 信息收集 | 直接验证 + 推进签约 | 不要反复建信（浪费机会） |
| 新客 + 信任焦虑 + 反复比价 | 蓝V+合同+案例组合拳 | 不要硬推，先解决安全感 |
