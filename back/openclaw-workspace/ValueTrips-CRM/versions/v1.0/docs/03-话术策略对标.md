## 重点套路详解

### #2 用户代问 — 最推荐的客服套路

**原理：** 搬出同类用户的视角，制造"这不是我问的，是跟你一样的人问的"的合理性，降低客户防御。

**话术模板：**
```
"之前有个跟您情况差不多的客户，ta也问了一模一样的问题，
ta说…… — 我给您分享一下ta后来的结果"
```

### #7 具体案例 — 高转化武器

**原理：** 抽象的说服不如一个真实故事。

**话术模板：**
```
"上上周有个客户，{身份标签}，一开始也担心{客户目前异议}。
后来ta选了{方案}，{具体结果}。
ta后来还说了一句特别打动我的话：{金句}"
```

### #15 共情复述 — 化解对抗

**原理：** 让客户感觉被真正理解，降低防御。

**话术模板：**
```
"我确认一下我理解得对不对：
您说的是{复述客户原话}，
核心是担心{提炼核心顾虑}，对吗？
如果是这样的话，我跟您说一个事实…"
```
