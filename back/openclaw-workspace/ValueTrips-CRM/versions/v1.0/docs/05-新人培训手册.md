## 二、客户人群画像与策略

### 👑 人群1：奢华蜜月

**典型用户画像**
- 新婚/纪念日出行，预算充足（5万+）
- 追求仪式感和专属体验
- 一般在备婚阶段或蜜月前1-3个月咨询

**需求动机**
- 🎯 要"不一样"的体验，不是普通旅行团
- 🎯 要发朋友圈能"赢"的素材
- 🎯 怕踩坑，毕竟是人生重要时刻

**开场话术**
```
"您好~ 恭喜新婚/纪念日呀🎉 
我们这边很多像您一样的新人选择XX舱/XX酒店，
我给您推荐几个最适合蜜月的方案？"
```

**推荐产品偏好**
| 产品 | 推荐理由 |
|------|---------|
| 国际商务舱 | 蜜月飞行体验升级 |
| 高端酒店礼遇 | 入住体验+蜜月布置 |
| 航司卡（白/金） | 长期出行权益 |

**常见异议与话术**
- "太贵了" → "蜜月是一辈子一次的事，多花一点钱换全程头等舱体验，回忆是无价的"
- "怕不靠谱" → "我们服务过XX对新人了，给您看看之前的蜜月案例"
- "想对比一下" → "建议先锁定名额，旺季蜜月档期很紧，错过了可能要等"

**关键动作**
- ✅ 强调「专属感」：专属对接群、蜜月礼遇清单
- ✅ 发真实案例：同类型新人的出行照片/反馈
- ✅ 节奏：客户感性时立刻推进，不要拖

**禁忌**
- ❌ 不要只谈价格不谈体验
- ❌ 不要用"经济实惠"这种词

### 💼 人群2：精英中产家庭

**典型用户画像**
- 30-45岁，有家庭有孩子
- 年出游2-4次，注重性价比和品质平衡
- 一般是家庭出行规划者（多为妈妈）

**需求动机**
- 🎯 全家出行，要照顾老人/孩子的需求
- 🎯 要省心（一站式搞定最好）
- 🎯 要性价比（不是最便宜，是花得值）

**开场话术**
```
"您好~ 一家人出行规划对吧？😊
我们很多家庭客户都选我们的服务，
主要是省心+性价比高。
您一家几口人？大概什么时间出发？"
```

**推荐产品偏好**
| 产品 | 推荐理由 |
|------|---------|
| 酒店礼遇 | 家庭房型+早餐/加床 |
| 国际商务舱 | 长途飞行带孩子更舒服 |
| 航司卡 | 全家出行积累里程 |

**常见异议与话术**
- "比携程贵" → "携程是第三方平台，我们直接跟酒店/航司对接，包含礼遇是携程没有的。您算上早餐、接送机这些，其实我们更划算"
- "我再看看" → "好的，不过我建议您先了解下，最近XX酒店的优惠套餐名额有限"
- "孩子太小怕麻烦" → "理解！我们有家庭客户专属客服全程跟进，您什么都不用操心"

**关键动作**
- ✅ 强调「省心」：全程有人跟进，一个群搞定
- ✅ 算总账：不是单价比，是整体价值比
- ✅ 给家庭案例：同类型家庭的出行方案

**禁忌**
- ❌ 不要推销过度高端的产品（除非对方主动问）
- ❌ 不要忽略孩子/老人的需求细节

### ✈️ 人群3：精英商务

**典型用户画像**
- 企业主/高管/频繁出差人士
- 30-50岁，差旅频率高（月均2-4次）
- 注重效率和身份感

**需求动机**
- 🎯 省时间（快速出票、优先通道、贵宾厅）
- 🎯 提升差旅体验（商务舱/休息室/快速通关）
- 🎯 性价比（高频出行，长期来算更划算）

**开场话术**
```
"您好~ 您平时出差多对吧？😊
像您这种高频差旅的客户，
用我们的航司卡方案一年能省不少。
您主要飞哪个航司比较多？"
```

**推荐产品偏好**
| 产品 | 推荐理由 |
|------|---------|
| 航司卡（终白/白金） | 高频出行必备 |
| 国际商务舱 | 差旅升级 |
| 酒店礼遇 | 差旅住宿品质 |

**常见异议与话术**
- "公司报销不需要" → "报销是公司的，权益是您自己的。商务舱的休息室、优先登机这些，自己用着舒服才是真的"
- "流程麻烦吗" → "不麻烦，签约后我们全程代办，您等着收卡就行"
- "怕影响现有会籍" → "我们处理过很多商务客户，会籍不受影响，合同里有保障条款"

**关键动作**
- ✅ 强调「效率」：流程精简、代办省心
- ✅ 用数据说话：一年飞XX次，省XX小时
- ✅ 谈ROI：投入vs回报算清楚

**禁忌**
- ❌ 不要啰嗦，商务人士时间有限
- ❌ 不要用太感性的语言（要理性+数据）

### 🏪 人群4：参展

**典型用户画像**
- 参展商/观展人员
- 出行时间集中在大型展会期（广交会、进博会等）
- 有固定预算，一般是企业行政或老板直接安排

**需求动机**
- 🎯 展会期间交通住宿一站式搞定
- 🎯 展期房源紧张，要提前锁定
- 🎯 团队出行（多人需要统一安排）

**开场话术**
```
"您好~ 是参加XX展会对吧？😊
展期房源和机票都比较紧张，
我们这边有展会专属方案，
您大概几个人过去？"
```

**推荐产品偏好**
| 产品 | 推荐理由 |
|------|---------|
| 酒店礼遇 | 展期周边酒店预订 |
| 国际商务舱 | 长途飞展会升级体验 |
| 航司卡 | 企业客户长期合作 |

**常见异议与话术**
- "我们自己订就行了" → "展期房源紧张，我们跟酒店有协议价，比您自己订更划算还含礼遇"
- "老板批的预算有限" → "理解，我给您看看预算内的最优方案"
- "团队人多能优惠吗" → "团队订单我们有阶梯优惠，人越多越划算"

**关键动作**
- ✅ 强调「锁定名额」：展期资源紧张
- ✅ 突出「团队优势」：多人统一安排更省心
- ✅ 快速出方案：不拖，展期客户时间敏感

**禁忌**
- ❌ 不要拖节奏，展期客户决策周期短
- ❌ 不要只推荐高端产品（要考虑预算）

### 🌱 人群5：年轻人

**典型用户画像**
- 20-30岁，刚工作/工作几年
- 第一次接触高端出行服务
- 追求体验但也关注价格

**需求动机**
- 🎯 想要"升级体验"（第一次坐商务舱的感觉）
- 🎯 性价比敏感（怕花冤枉钱）
- 🎯 社交分享（小红书/朋友圈素材）

**开场话术**
```
"哈哈第一次了解这个对吧？😄
没事，我给您简单说下，
很多人像您一样一开始也是不太了解，
后来发现其实比自己订划算多了~"
```

**推荐产品偏好**
| 产品 | 推荐理由 |
|------|---------|
| 酒店礼遇 | 体验升级入门 |
| 国际商务舱 | 性价比之选 |
| 航司卡入门版 | 长期权益积累 |

**常见异议与话术**
- "太贵了，我还是学生/刚工作" → "正因为刚工作才更要会花啊！我给您算一笔账，这个卡一年下来比单次买省XX，等于越飞越赚"
- "怕被骗" → "我们有蓝V认证+正规合同，您放心，很多年轻客户都是第一次，后来都成了回头客"
- "我再想想" → "没事，加个联系方式，您有需要随时找我，有问题尽管问"

**关键动作**
- ✅ 降低门槛：用"第一次"心态沟通
- ✅ 算对比账：自己买vs通过我们买
- ✅ 给安全感：多解释、多给案例

**禁忌**
- ❌ 不要高高在上（"这个你们可能不懂"）
- ❌ 不要push太紧

### 💻 人群6：远程办公数字游民

**典型用户画像**
- 自由职业/远程工作者/创业者
- 经常在不同城市/国家之间移动
- 对灵活性要求高，长期出行需求

**需求动机**
- 🎯 长期出行的成本控制
- 🎯 飞行灵活性和舒适度（经常飞）
- 🎯 网络/办公环境（酒店办公需求）

**开场话术**
```
"您好~ 是经常在不同城市跑对吧？😊
像您这样的数字游民客户我们有不少，
长期飞的话用航司卡方案最划算。
您现在主要在哪些城市/国家之间跑？"
```

**推荐产品偏好**
| 产品 | 推荐理由 |
|------|---------|
| 航司卡 | 高频出行的最优解 |
| 酒店礼遇 | 长期住宿的品质保障 |
| 国际商务舱 | 长途飞行更舒适 |

**常见异议与话术**
- "我居无定所，怕麻烦" → "正因为您经常换地方才更需要！我们全程线上对接，您在哪儿都能办"
- "预算不稳定" → "没事，我给您推荐灵活方案，根据您的实际出行频率来选"
- "酒店要能办公的" → "我们推荐的酒店都有商务中心和高速网络，适合远程办公"

**关键动作**
- ✅ 强调「远程可办」：全程线上，人在哪都行
- ✅ 突出「灵活性」：方案可以根据出行频率调整
- ✅ 聊生活方式：认同数字游民的生活方式

**禁忌**
- ❌ 不要用"稳定""固定"这种词
- ❌ 不要怀疑他们的生活方式（"这样能赚钱吗"）
