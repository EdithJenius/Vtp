# Step A-F × 6类人群 · 话术模板

> 在 Frank 决策树的基础上，每个步骤按客户人群匹配不同话术。

---

## Step A · 小红书私信

### 通用招呼 → 探业务 → 引导留lxfs

**通用话术（不分人群）：**
```
"您好~ 有什么可以帮您的吗？😊"
```

**判断人群后补充话术：**
| 人群 | 判断后切入 |
|------|-----------|
| 👑 蜜月 | "是看蜜月出行方面的对吗？🎉" |
| 💼 家庭 | "一家人出行规划？😊" |
| ✈️ 商务 | "出差需要了解？" |
| 🏪 参展 | "参加XX展会？" |
| 🌱 年轻人 | "第一次了解我们？我给您介绍下~" |
| 💻 游民 | "经常在不同城市跑对吗？" |

**引导留lxfs：**
```
"方便加个微信不？我让专员把详细方案发给您~"
```

## Step B · 加微信 / 拉群

**通过验证后：**
```
"您好~ 我是ValueTrips的XX，您从小红书咨询的对吧？
我拉个群方便专员跟您对接~"
```

**群命名规则：**
```
客服花名 - 客户微信名 - 人群标签 - 业务
示例：阿杰 - 小李 - 蜜月 - 国泰商务舱
```

## Step C · 探需求 + 报价

### 按人群的必问项差异

| 人群 | 必问项 |
|------|--------|
| 👑 蜜月 | 出发日期 / 目的地 / 人数 / 预算 / 有什么特别想要的体验 |
| 💼 家庭 | 出发日期 / 目的地 / 人数(含孩子年龄) / 预算 / 对酒店的要求 |
| ✈️ 商务 | 常飞航司 / 差旅频率 / 每月飞行次数 / 主要航线 / 公司报销还是自费 |
| 🏪 参展 | 展会名称 / 时间 / 人数 / 住宿要求 / 交通方式 |
| 🌱 年轻人 | 出行目的 / 预估频率 / 预算范围 / 之前用过类似服务吗 |
| 💻 游民 | 常去城市/国家 / 出行频率 / 住宿偏好 / 是否需要办公条件 |

### 报价后常见反应 × 人群话术

| 反应 | 蜜月 | 家庭 | 商务 | 参展 | 年轻人 | 游民 |
|------|------|------|------|------|-------|------|
| 接受 | → Step E | → Step E | → Step E | → Step E | → Step E | → Step E |
| "太贵了" | 一辈子一次 | 算含礼遇 | 省时就是钱 | 展期特惠 | 第一次不懂正常 | 长期省更多 |
| "比XX贵" | 体验不同 | 礼遇不一样 | 服务不一样 | 展会协议价 | 我给您算算 | 灵活方案 |
| "再想想" | 蜜月档期紧 | 套餐名额少 | 季度名额限制 | 展期房源紧 | 加好友再聊 | 随时可联系 |

## Step D · 异议处理

### 按人群的异议优先级

| 人群 | 最可能的异议 | 次要异议 |
|------|------------|---------|
| 👑 蜜月 | 怕不靠谱（人生大事） | 太贵了 |
| 💼 家庭 | 比价（家庭预算） | 怕后续没人管 |
| ✈️ 商务 | 流程麻烦 | 对现有会籍的影响 |
| 🏪 参展 | 价格 | 团队安排不灵活 |
| 🌱 年轻人 | 怕被骗 | 太贵了/不懂 |
| 💻 游民 | 不灵活/不适合 | 远程能不能办 |

### 异议处理话术（按人群）

```
【蜜月】"我们服务过XX对新人，没出过问题
         — 蜜月案例您可以看看"

【家庭】"价格您可以对比，但我们含的礼遇
         别家没有 — 算下来其实更划算"

【商务】"流程很简单，签约→打款→提交，
         全程我们代办，您等着收卡就行"

【参展】"展期房源我们自己都紧张，
         建议尽早定下来"

【年轻人】"我们有蓝V认证+正规合同，
          很多像您一样的第一次客户都在我们这办的"

【游民】"全程线上对接，您在哪儿都能办，
        方案也可以根据您的频率灵活调整"
```

## Step F · 售后 / 等待期

### 按人群的跟进重点

| 人群 | 等待期最关心 | 延伸服务方向 |
|------|------------|------------|
| 👑 蜜月 | 能不能按时拿到 | 酒店蜜月布置/接机服务 |
| 💼 家庭 | 全家人的信息都对了没 | 亲子酒店/儿童餐食 |
| ✈️ 商务 | 什么时候能用 | 快速通道/贵宾厅 |
| 🏪 参展 | 多人信息汇总确认 | 团队接送/商务服务 |
| 🌱 年轻人 | 到了怎么用 | 使用攻略/注意事项 |
| 💻 游民 | 能不能改期/换目的地 | 多目的地方案 |

### 延伸服务推荐策略

```
下卡后/出行后，按人群推延伸服务：
  👑 蜜月客户 → 推蜜月酒店套餐
  💼 家庭客户 → 推亲子住宿/家庭商务舱
  ✈️ 商务客户 → 推酒店会籍匹配
  🏪 参展客户 → 推下次展会提前预约
  🌱 年轻客户 → 推升级版方案
  💻 游民客户 → 推更多目的地选择
```
