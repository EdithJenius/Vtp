## 二、素材在哪

### 2.1 Bitable 素材匹配表

路径：**⑤ 素材匹配** 表

每个镜头的字段说明：

| 字段 | 说明 | 怎么用 |
|:----|:-----|:-------|
| **镜头编号** | 1-20 | 按此顺序排列即可 |
| **画面描述** | 画面内容说明 | 理解该镜头需要什么画面 |
| **对应文案** | 这段画面的口播文案 | 卡节奏的依据 |
| **素材链接** | YouTube 链接（含时间戳） | 点击直接跳到对应时间点 |
| **画面分割** | 所属章节 | 知道这一帧来自哪一段 |
| **素材类型** | 动物/风景/酒店/转场/人物 | 快速筛选同类素材 |
| **是否已下载** | 是/否 | 确认本地是否有文件 |

## 三、快速上手（3分钟流程）

### Step 1: 导入时间线

**Premiere Pro:**
```
文件 → 导入 → 选择 timeline/坦桑尼亚狂野海岛_timeline.edl
→ 确认时间基准为 25fps
→ 时间线自动排列20个片段（入点/出点已设好）
```

**Final Cut Pro:**
```
文件 → 导入 → XML → 选择 timeline/坦桑尼亚狂野海岛_timeline.fcpxml
→ 素材片段自动排好
```

**DaVinci Resolve:**
```
文件 → 导入 → 时间线 → EDL → 选择 .edl 文件
```

### Step 2: 挂载代理文件

如果剪辑机器性能不够跑 4K：

```
Premiere Pro: 项目面板 → 右键 → 代理 → 连接代理
→ 选择 clips/_proxy/ 目录 → 自动匹配

剪辑时用720p代理，导出时自动切换回原片
```

### Step 3: 套用口播音频

```
① 向运营/文案拿最终版口播录音（WAV/MP3）
② 拖入时间线音轨
③ 根据 Bitable「对应文案」字段，按节奏微调素材片段长度
④ 去除不需要的片段，补充转场
```

### Step 4: 精剪要点

| 素材类型 | 建议时长 | 技巧 |
|:--------|:-------:|:-----|
| 动物特写（狮子/猎豹） | 3-5秒 | 抓眼睛/动作关键帧 |
| 风景/航拍 | 3-4秒 | 缓慢推轨或横移 |
| 酒店/住宿 | 3-4秒 | 先外景后内景 |
| 人物 | 2-3秒 | 不要正脸，背影/侧脸 |
| 转场 | 1-2秒 | 用叠化过渡 |

### Step 5: 调色规范

主色调：暖色（金色时刻/日落感）
不混搭：同一视频保持色调统一
避免：过饱和、暗部死黑

## 五、常见问题

### Q: 素材不够怎么办？
A: 素材匹配表已关联 YouTube 主视频的 11 个章节时间轴。点击素材链接可直接跳到对应时间点，手动裁剪额外镜头。

### Q: 素材分辨率/比例不一致？
A: 主要素材为 4K 或 1080p。最终输出设置为 1920×1080 (16:9)，竖屏版（9:16）需重新裁剪构图。

### Q: 怎么加BGM？
A: 当前版本暂无预设BGM。建议根据画面节奏选择：
- 野生动物 → 非洲鼓/管弦乐/自然音效
- 桑给巴尔 → 轻快海岛风/吉他
- 日落/情感结尾 → 钢琴/弦乐渐强

### Q: 音频处理要注意什么？
A: 
- 口播音量 -6dB 到 -3dB
- BGM 音量 -18dB 到 -12dB
- 环境音（自然音效） -15dB 到 -10dB
