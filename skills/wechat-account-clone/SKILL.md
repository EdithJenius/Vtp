# 公众号对标克隆 Skill

> 输入参考公众号文章链接 → AI拆解风格指纹 → 模仿生成你的公众号内容

## 触发词

- "克隆这篇公众号风格"
- "模仿XX的风格写一篇"
- "对标这个公众号"
- "做风格拆解"

## 工作流

```
输入: 参考文章链接(mp.weixin.qq.com/s/...)
  │
  ├─ Step 1: 抓取全文内容
  ├─ Step 2: 拆解风格指纹(12维度)
  ├─ Step 3: 生成风格画像报告
  │
输入: 你的选题/产品/主题
  │
  ├─ Step 4: 按风格画像生成正文
  ├─ Step 5: 标题生成(3-5个候选)
  ├─ Step 6: 合规校验
  │
输出: 完整公众号文章
```

---

## Step 1: 抓取文章

```python
from web_fetch import fetch

url = "https://mp.weixin.qq.com/s/{article_id}"
content = fetch(url)  # 自动提取正文
```

公众号文章 URL 格式: `mp.weixin.qq.com/s/{id}`

直接用 `web_fetch` 工具抓取即可，raw-html 模式能提取完整正文（含公众号名称、作者信息）。

---

## Step 2: 风格拆解（12维度）

对抓取到的文章，从以下12个维度进行拆解：

### 2.1 基础信息
| 维度 | 说明 |
|:----|:-----|
| 公众号名称 | |
| 作者/IP名 | |
| 文章定位 | 带货/种草/攻略/资讯/情感/观点 |

### 2.2 标题风格
| 维度 | 说明 |
|:----|:-----|
| 标题长度 | 字符数 |
| 标题结构 | 陈述句/疑问句/感叹句/数字型/反差型 |
| 标题钩子 | 使用的hook技巧（悬念/痛点/利益/热点/对比） |
| Emoji使用 | 是否带emoji, 什么位置, 密度 |

**常见标题结构库：**
1. 数字型：`「N个XXX，第N个绝了」`
2. 反转型：`「去之前觉得贵，退房时发现赚了」`
3. 痛点型：`「去XXX最怕什么？这N个坑我替你踩了」`
4. 场景型：`「如果你只有N天假期，我建议你来XXX」`
5. 揭秘型：`「XXX员工不会告诉你的N个XXX」`
6. 对比型：`「XXX vs YYY，同价位我选前者」`
7. 限定型：`「XXX这个季节去，景色翻倍」`
8. 身份型：`「住过N次XXX，告诉你这N个隐藏服务」`

### 2.3 开头策略
| 维度 | 说明 |
|:----|:-----|
| 首句类型 | 场景描写/痛点提出/共识建立/反常识/热点引入 |
| 开头长度 | 到正文的第几个段落进入正题 |
| 钩子手法 | 前3句如何抓住读者 |

### 2.4 正文结构
| 维度 | 说明 |
|:----|:-----|
| 段落长度 | 短段落(1-2句)/中段落(3-5句)/长段落(6句+) |
| 分段方式 | 分隔符/小标题/空行/emoji |
| 信息组织 | 总-分-总/并列/递进/按场景/按问题 |
| 节奏感 | 快（短句密集）/慢（长句铺陈）/混合 |

### 2.5 语气调性
| 维度 | 说明 |
|:----|:-----|
| 人称 | 第一人称(我)/第二人称(你)/第三人称 |
| 正式度 | 口语化/半正式/杂志感 |
| 情绪浓度 | 高（感叹号密集）/中/低（克制） |
| 常用语气词 | 啊/吗/呢/哦/呗/吧 的使用频率 |

### 2.6 信息密度
| 维度 | 说明 |
|:----|:-----|
| 品牌/产品提及率 | 每百字出现几次 |
| 数据使用 | 价格/数量/时间/比例 的使用频率 |
| 背书策略 | 专家/品牌/名人/官方/数据 的引用方式 |

### 2.7 视觉格式
| 维度 | 说明 |
|:----|:-----|
| Emoji使用 | 频率/位置/类型（表情/符号/箭头） |
| 标点偏好 | 感叹号/引号/破折号/省略号 的使用 |
| 分段标记 | 有无分隔符（--- / *** / 空行） |
| 重点标记 | 加粗/引用/缩进 的使用 |

### 2.8 转化手法
| 维度 | 说明 |
|:----|:-----|
| 转化类型 | 直接(链接/二维码)/间接(引导搜索)/软植入 |
| 紧迫感策略 | 限时/限量/涨价/即将结束 |
| 信任建立 | 不约可退/亲测/退改政策/读者反馈 |
| CTA位置 | 文中/文末/分段穿插 |

### 2.9 结尾模式
| 维度 | 说明 |
|:----|:-----|
| 结尾类型 | 总结型/呼吁型/金句型/引导关注型 |
| 个人IP | 是否有固定签名/自我介绍/口头禅 |
| 互动引导 | 点赞/在看/评论/转发/收藏 |

### 2.10 选词偏好
| 维度 | 说明 |
|:----|:-----|
| 高频词 | Top 20高频词汇 |
| 特色词汇 | 该号独有的表达/梗/口头禅 |
| 形容词倾向 | 夸张(绝了/爆了)/克制(不错/挺好)/文艺 |

### 2.11 价值观定位
| 维度 | 说明 |
|:----|:-----|
| 核心主张 | 这个号传递的核心价值观 |
| 读者画像 | 目标读者是谁 |
| 人设 | 作者在读者心中的形象 |

### 2.12 商品推介模式
| 维度 | 说明 |
|:----|:-----|
| 推介位置 | 开头直接推/中间穿插/文末集中 |
| 描述方式 | 参数罗列/体验描述/对比加价 |
| 价格呈现 | 原价vs活动价/拆分计算/与其他对比 |
| 售后保障 | 是否强调可退/有效期/使用限制 |

## Step 4-6: 按风格生成内容

### 生成流程

1. **输入你的选题** — 你要写什么产品/目的地/话题
2. **获取风格画像** — 从之前的拆解结果加载
3. **按画像生成正文** — 遵循结构/语气/节奏/转化手法
4. **生成标题** — 3-5个候选，匹配目标标题风格
5. **合规校验** — 检查违禁词、广告法红线

### 生成原则

- ❌ 不能直接抄袭原文句子
- ✅ 模仿的是结构、语气、节奏、信息组织方式
- ✅ 保留目标公众号的"口头禅"和标志性表达
- ✅ 遵守公众号排版规范

## 踩坑记录

### 2026-06-09

1. **微信公众号文章可抓取** → `mp.weixin.qq.com/s/{id}` 格式可直接用 `web_fetch` 抓取，正文部分（标题+公众号名+作者+正文）能完整提取。HTML中混有大量JS/微信SDK代码需过滤。
2. **搜狗微信搜索局限性** → `weixin.sogou.com` 虽然能搜公众号文章，但返回的链接是代理URL（带token），无法直接跳转。搜公众号主页（type=1）返回结果较少，搜文章（type=2）结果杂且不按时间排序。最佳方式：直接给具体文章链接。
3. **百度搜索微信文章** → `site:mp.weixin.qq.com` 加关键词搜索会触发百度反爬验证码，不可靠。
4. **风格拆解vs抄袭界线** → 模仿的是结构/语气/节奏/信息组织方式，不是抄句子。12维度拆解确保了这一点。
