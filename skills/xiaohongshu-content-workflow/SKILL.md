# 小红书内容工坊

> 对标拆解 → 爆款分析 → 多维裂变

## 适用场景

- 运营团队需要批量产出小红书笔记
- 拆解对标账号的爆款笔记，提取可复制方法论
- 从不同内容维度裂变生成多篇变体文案
- 追热点快速产出，保持账号日更节奏

---

## 工作流总览

```
┌─────────────┐   ┌──────────────┐   ┌──────────────┐
│ 📎 输入对标  │ → │ 🔍 抓取同类   │ → │ 🧠 多维拆解   │
│ 笔记+要点    │   │ 爆款笔记      │   │ (5维度分析)   │
└─────────────┘   └──────────────┘   └──────────────┘
                                              ↓
       ┌──────────────┐   ┌──────────────┐
       │ 📤 输出/交付   │ ← │ ✨ 裂变生成   │
       │ (文案+分析)   │   │ N篇变体      │
       └──────────────┘   └──────────────┘
```

---

## 输入格式

用户只需提供：

```
链接：<小红书笔记URL>
学习要点：
1. <标题手法>
2. <选题角度>
3. <内容结构>
4. <视觉风格>
关键词：<选题方向>
```

---

## Step 1：输入对标

### 用户提供
- **小红书笔记链接** — 对标的爆款笔记
- **学习要点** — 重点拆解哪些方面（标题、选题、素材、金句、动机）
- **选题关键词** — 内容方向（如"暑假去哪玩、蜜月旅行"）

### 我执行
- 确认链接有效性
- 记录用户指出的学习重点
- 明确本次裂变的目标方向

---

## Step 2：搜索同类爆款

### 执行策略
1. 通过 `browser` 或 `web_fetch` 访问小红书
2. 搜索与对标笔记相似的热门内容
3. 收集 3-5 篇同类型爆款笔记
4. 提取共性特征

### 关键词搜索公式
```
[选题关键词] + site:xiaohongshu.com
[对标笔记的核心词] + 爆款/热门/收藏
[目标人群] + [痛点] + 攻略/推荐/避坑
```

---

## Step 3：多维拆解（5维度框架）

按用户提供的「内容拆解模板」，每篇笔记拆解以下 5 个维度：

### ① 标题拆解
- **公式分析：** 用数字？场景代入？制造对比？设置悬念？蹭热点？
- **人群圈层：** "这是写给谁看的"——找到标题中锁定目标用户的关键词
- **情绪钩子：** 利用哪种心理驱动？
  - 损失厌恶（怕吃亏/避雷/劝退）
  - 数字悬念（30天/5个细节/花费10w）
  - 阶层向往（人生建议/松弛感/天花板）
  - 信息差/利益（保姆级/SOP/内部资料）
  - 反差/创新（谁说.../真相是...）
- **关键词布局：** 埋了哪些大词和长尾词（SEO）
- **视觉装饰：** 符号/表情/竖线分隔

### ② 选题拆解
- **目标群体：** 显性标签（直接写出来的）+ 隐性画像（消费力/场景判断）
- **人群痛点：** 恐惧型（害怕失去）/ 迷茫型（不知路）/ 虚荣型（求认同）
- **选题核心：** 属于哪种类型？
  - A. 信息差核心（我知道你不知道的）
  - B. 效率核心（节省时间的）
  - C. 情绪/嘴替核心（帮你喊出内心话）
  - D. 审美/造梦核心（给你看理想生活）

### ③ 素材/视觉拆解
- **图片：** 构图与视线、色调情绪、信息密度（单图极简 vs 拼图极繁）
- **视频：** 黄金前3秒、BGM与卡点
- **金句：** 焦虑/痛点型（扎心）| 情绪/价值观型（升华）| 认同型（圈层）

### ④ 点击动机
- **A. 审美驱动：** 太美了/太高级了
- **B. 利益驱动：** 感觉有干货/能避坑
- **C. 情绪驱动：** 焦虑/渴望/猎奇

### ⑤ 可复制手法总结
- 标题公式中最高频的 2-3 种
- 选题角度中差异化的切入点
- 内容结构中的钩子设计模式

---

## Step 4：裂变生成（6大驱动维度）

从以下维度生成多篇不同角度的笔记文案：

### 可选的裂变维度

| 驱动维度 | 核心逻辑 | 示例方向 |
|---------|---------|---------|
| ⏰ **时间/事件驱动** | "此时不做，更待何时" | 520、暑假、春节、樱花季 |
| 👥 **圈层/兴趣驱动** | "这是写给你看的" | 毕业生、亲子、商务、追星族 |
| 🎨 **精神/审美驱动** | "我向往的生活" | 自然美学、人文美学、设计酒店 |
| 🌊 **感官/生活驱动** | "先让你感受到" | 味蕾旅行、夏日感官、市井烟火 |
| 🧘 **疗愈/松弛驱动** | "你需要休息一下" | 逃离城市、森林温泉、躺平旅行 |
| 💎 **物欲/仪式感驱动** | "你值得更好的" | 人生必住、攒钱打卡、一生一次 |

### 每篇笔记的输出结构
```
【标题】A/B 两个版本
【正文】完整文案（300-500字）
【标签】5-8个推荐标签
【封面/配图建议】
【发布时间建议】
```

---

## 输出交付

最终交付内容包括：

```
📊 一、对标笔记拆解报告
  - 5维度完整拆解
  - 可复用的手法总结

📈 二、同类爆款发现
  - 3-5篇相似爆款笔记概览
  - 共性规律提炼

✍️ 三、裂变文案（N篇）
  - 每篇含标题AB版 + 正文 + 标签 + 配图建议
  - 每篇角度不同，覆盖不同驱动维度

💡 四、选题库更新建议
  - 新的选题方向
  - 热点时间轴建议
```

## 使用示例

### 用户输入
```
链接：https://www.xiaohongshu.com/explore/xxx
学习要点：
1. 标题用了"暑假+数字+目的地"公式
2. 封面是拼图风格，左右对比
3. 正文开头直击打工人"想去玩但没假"的痛点
4. 结尾引导收藏和@好友
关键词：暑假亲子游、避暑胜地
```

### 我输出的裂变方向示例
```
⏰ 时间驱动 → 「2026暑假第一波特价机票来了」
👥 圈层驱动 → 「带娃党必看！暑假亲子游天花板」
🎨 审美驱动 → 「宫崎骏夏天真实存在，就在这个避暑小城」
🧘 疗愈驱动 → 「打工人周末逃离计划：2天1夜避暑攻略」
💎 仪式感驱动 → 「30岁前一定要去的5个地方」
```

## 注意事项

- 小红书需要登录态才能搜索，使用 browser 时确保已登录
- 内容需遵守小红书社区规范，避免违禁词/敏感词
- 生成的文案仅供修改参考，发布前建议人工审核
- 标签不要堆砌，选最精准的 5-8 个即可
- 发布时间推荐：工作日 12:00 或 20:00~22:00
